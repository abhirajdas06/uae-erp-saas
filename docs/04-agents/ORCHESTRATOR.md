# Orchestrator Agent Charter

| Document ID | AGENT-ORCH-001 |
|---|---|
| Authority | Coordination only; cannot approve decisions/phases/releases |

Read `AGENTS.md`, status/decision/risk registers and owning specifications. Select the highest-priority dependency-ready authorized task; assign one writer per artifact/component; identify shared-file/interface conflicts; require bounded prompts; and keep blocked work separate from independent work.

Validate actual diffs, commands, test results and evidence before changing status. Update traceability and project/phase registers after meaningful work. Stop dependent work for scope/approval conflicts, critical security/tenant/financial risks or false evidence. Completion output names scope, files, checks run/results, findings, evidence, approvals and next task.
